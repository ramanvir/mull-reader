Install Mull Reader

Mull Reader is a progressive web app: install it once from the browser and it opens in its own window with its own icon, launches from your home screen or dock, and works fully offline. There is no app store and nothing to download — installing simply tells your device to keep the app around.

Even without installing, the site works offline in the browser after your first visit. Installing just makes it feel like a native app.

iPhone and iPad

Use Safari — other iOS browsers cannot install web apps.

  1. Open mullreader.com in Safari.
  2. Tap the Share button (the square with an arrow pointing up).
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add. The Mull Reader icon appears on your home screen and opens full-screen, without Safari's toolbars.

Android

In Chrome (and most Chromium browsers such as Brave or Edge):

  1. Open mullreader.com.
  2. Tap the ⋮ menu in the top-right corner.
  3. Tap Add to Home screen (on some versions it says Install app), then confirm.

In Samsung Internet, tap the menu, then Add page to → Home screen. In Firefox for Android, tap the menu, then Add to Home screen.

Windows, Linux, and Chromebooks

In Chrome or Edge:

  1. Open mullreader.com.
  2. Click the install icon at the right end of the address bar (a screen with a downward arrow), or open the browser menu and choose Install Mull Reader… (in Edge: Apps → Install this site as an app).
  3. Confirm. The app gets its own window, taskbar icon, and Start-menu / launcher entry.

Desktop Firefox does not support installing web apps, but the site still works offline in a normal tab.

macOS

In Safari (macOS Sonoma or later): open the site, then choose File → Add to Dock… and confirm. In Chrome or Edge, use the install icon in the address bar exactly as described above — the app lands in your Applications folder and the Dock.

E-ink readers and other devices

Any device with a Chromium-based browser can install the app the same way as Android or desktop. On devices that cannot install it, just bookmark the site — offline support and the reading preferences (including E-ink mode, in the menu) work the same in a plain browser tab.

Uninstalling

Remove it like any app: delete the icon from your home screen (iOS/Android), or right-click the app icon and choose uninstall (Windows), or drag it out of Applications (macOS). Chrome and Edge also list installed web apps under chrome://apps and edge://apps. Your reading preferences live in the browser and survive reinstalling.
