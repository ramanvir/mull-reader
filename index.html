Mull Reader

A lightweight, open-source markdown reader for knowledge created by AI agents — and a place to edit it or write your own. Mobile friendly, and all documents remain local, always. A progressive web app: install it and it works offline.

An installed app can only open through the Files app. To reach Google Drive there, turn it on in Files → Browse → ⋯ → Edit, or copy the document in the Drive app and paste it here.
